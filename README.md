# حساب الشيفت

تطبيق ويب بسيط يساعدك على متابعة أوردرات الشيفت، حساب الكاش المتبقي، صافي الربح، ومبلغ الحساب مع المطعم في لحظة واحدة.

## المميزات

- إضافة أوردرات كاش أو فيزا
- حساب المبلغ المتبقي معك في الكاش
- حساب صافي الربح من رسوم التوصيل
- تحديد ما إذا كنت مديناً أو المطعم مدين لك
- إمكانية تعديل أو حذف الأوردرات
- حفظ البيانات محلياً في المتصفح باستخدام `localStorage`
- إمكانية مشاركة ملخص الشيفت

## التشغيل

هذا المشروع عبارة عن صفحة HTML ثابتة، لذلك لا يحتاج إلى تثبيت تبعيات أو خادم Node.js.

### الطريقة السريعة

1. افتح ملف `index.html` مباشرة في المتصفح.
2. أو شغّل خادم محلي بسيط:

```bash
python -m http.server 8000
```

ثم افتح المتصفح على:

```text
http://localhost:8000
```

## الاستخدام

- أدخل سعر الأوردر (إذا كان دفع كاش) أو اترك الحقل فارغاً في حالة الدفع بالفيزا
- أدخل رسوم التوصيل
- اضغط على "ضيف الأوردر"
- يمكنك من القائمة مراجعة الأوردرات، تعديلها أو حذفها
- زر "شيفت جديد" يفرغ القائمة

## ملاحظات

- يتم حفظ البيانات في المتصفح فقط، لذلك إذا تم مسح بيانات المتصفح فلن تظهر البيانات.
- التطبيق مصمم خصيصاً للعرض على الهاتف المحمول مع واجهة RTL باللغة العربية.
